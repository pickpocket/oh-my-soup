`ssh://<session|host>/<path>` or TRAMP `/ssh:[user@]host[#port]:path`: remote UTF-8 file/dir (max 1 MiB) for read/write/grep; session = `ssh` device name, host = configured or OpenSSH destination; connects lazily. Bare `ssh://` lists hosts. URL: encode `:` `?` `#`; TRAMP: literal filenames, no read selectors; empty/relative/`~/` starts at remote home. Single-hop SSH only; named credentials cannot be overridden. Needs verified POSIX remote; else `bash target`.
