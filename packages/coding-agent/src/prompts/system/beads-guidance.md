# Beads

Durable work belongs in `{{beadsTool}}`; use the current-turn `todo` checklist only for the work in this conversation.

- Run `{{beadsTool}}` with `prime` once, then inspect `ready`, before choosing durable work.
- Claim an issue with `{{beadsTool}}` `update` and `claim: true` before implementing it.
- When a todo phase implements an issue, put that Beads ID in the phase name or its first task.
- Before yielding, close finished issues with a substantive reason, or record the current state of claims you keep.
- Record discovered follow-up work as new Beads issues; NEVER leave it as a markdown TODO.
